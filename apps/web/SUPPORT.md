# 💬 CampusOS AI Community Support & Help

Thank you for using **CampusOS AI**! Here is how you can get help, report bugs, or request features.

---

## 🙋 Getting Help

- **Documentation**: Check our detailed technical guides in the [`docs/`](./docs) folder:
  - [Architecture Overview](./docs/Architecture.md)
  - [AI & Multi-Agent Platform](./docs/AI.md)
  - [Security Architecture](./docs/Security.md)
  - [Developer Guide](./docs/DeveloperGuide.md)
  - [Testing & Quality Assurance](./docs/Testing.md)
- **GitHub Discussions**: Have a question about architecture, local setup, or customization? Ask in our [GitHub Discussions](https://github.com/Rishisharma029/campusOS/discussions).

---

## 🐛 Reporting Issues

- **Bug Reports**: Search existing [GitHub Issues](https://github.com/Rishisharma029/campusOS/issues) before opening a new issue. Include reproduction steps, environment details, and relevant console logs.
- **Security Vulnerabilities**: Do **NOT** report security bugs in public issues. Follow our [Security Policy](./SECURITY.md) to disclose vulnerabilities privately.

---

## 💡 Feature Requests

Have an idea for CampusOS AI? Submit a feature request via [GitHub Issues](https://github.com/Rishisharma029/campusOS/issues/new) detailing the problem, proposed solution, and target layer (Layer 1, 2, or 3).
